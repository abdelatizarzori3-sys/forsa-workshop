# فرصة — مساحة برو الوظيفية

هذه إضافة إلى تطبيق فرصة القائم، وليست صفحة تعريف ببرو. تحتفظ `/` بورشة الخدمات والحاسبة، وتفتح `/workspace` مساحة العروض والعملاء بعد تسجيل دخول حقيقي بحساب Manus.

## الوظائف

تحفظ مساحة العمل العروض والعملاء وهوية النشاط في MySQL، مرتبطة بهوية صاحب الحساب. يمكن إنشاء العروض وتعديل نطاقها وقيمتها وكلفتها وعملتها وعميلها وصلاحيتها وحالتها، وحذفها. الحالات «مسودة، مرسل، مقبول، مرفوض» معلومات يسجلها المستخدم؛ لا يُرسل البريد تلقائيًا ولا تعني الحالة أن دفعة وصلت. يمنع الخادم تعديل نسخة قديمة فوق تعديل أحدث، ويمنع حذف عميل مرتبط بعرض قبل فك الارتباط.

يمكن حفظ اسم النشاط وبيانات التواصل وشعار PNG/JPEG حتى 500 كيلوبايت وأبعاد 2000 × 2000. يصدر الخادم PDF عربيًا فعليًا من العرض المحفوظ، مع خط عربي مضمّن وشعار النشاط وبيانات العميل. لا يعرض الملف كلفة التنفيذ الداخلية أو الهامش، وليس فاتورة أو إثبات دفع. التصدير محمي بهوية المالك وبصلاحية تجربة برو الخادمية.

المجاني يسمح بثلاثة عروض محفوظة. تبدأ تجربة برو المجانية لسبعة أيام فقط بطلب صريح من المستخدم، مرة واحدة لهوية الحساب. لا توجد رسوم أو بطاقة أو تجديد تلقائي، ولا يعد هذا اشتراكًا مدفوعًا. بعد الانتهاء تبقى العروض مقروءة وقابلة للتعديل، لكن التصدير وإنشاء عروض فوق الحد المجاني يُرفضان. شراء الاشتراك والتحصيل المدفوع غير مفعّلين؛ يحتاجان بلد التحصيل والحساب والأسعار قبل تنفيذ مزود دفع حقيقي.

## الإعداد والتشغيل

يتطلب التشغيل Node 22 وpnpm 10.18.1 وMySQL متوافقًا وChromium لتوليد PDF. يوفر Dockerfile الاعتماديات والخطوط. تحتاج البيئة الخادمية إلى `DATABASE_URL` و`MANUS_PROJECT_ID` و`MANUS_JWT_SECRET` و`MANUS_OAUTH_PORTAL_URL` و`MANUS_OAUTH_API_URL`. هذه قيم يوفرها مشروع Manus المهيأ بالخادم وقاعدة البيانات. ليست متاحة تلقائيًا لمجرد استنساخ مستودع GitHub؛ تضبط عبر بيئة الاستضافة الآمنة، ولا تُنسخ إلى Git أو الواجهة. `CHROMIUM_PATH` اختياري ويبدأ بـ`/usr/bin/chromium`. للنطاق الخاص خارج نطاقات Manus، يسمح `FORSA_PUBLIC_ORIGIN` بأصول HTTPS صريحة مفصولة بفواصل.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm exec tsx server/migrate.ts
corepack pnpm check
corepack pnpm test
corepack pnpm build
corepack pnpm dev
# للإنتاج بعد البناء وتهيئة البيئة:
corepack pnpm start
```

الترحيلات إضافية، مسجلة بالإصدار، لا تزرع مستخدمًا أو عروضًا تجريبية، ولا تعمل تلقائيًا عند كل بدء. `/health` يرجع `ready` فقط حين تتهيأ المصادقة والجداول. قاعدة تطوير Manus وقاعدة النسخة المنشورة واحدة، ولذلك تستخدم اختبارات HTTP مستودعًا معزولًا في الذاكرة وJWT خاصة بالاختبارات؛ ليست هناك هوية تجريبية أو تجاوز تسجيل دخول في التطبيق الفعلي. اختبار دورة OAuth يستخدم استجابات مزود معزولة؛ لا يثبت وحده نجاح تسجيل دخول صاحب الحساب عبر المزود الحي.

## الحماية والاختبار

يتحقق الخادم من توقيع HS256 وانتهاء الجلسة ومعرّف المشروع و`openId`. ترتبط nonce تسجيل الدخول بمتصفح المستخدم وتُستهلك مرة واحدة في قاعدة البيانات، وتبقى صالحة عند انتقال الطلب بين مثيلات الخادم. كل طلب معدل يتطلب CSRF مربوطًا بالجِلسة. كل استعلام بيانات مقيد بالمالك، ولا يتيح مسار PDF الوصول إلى عرض حساب آخر. يتلقى API بيانات JSON متحققًا منها، ولا يرد بصفحة HTML للطرق المفقودة. شعار المستخدم صورة raster محدودة، ولا يسمح التصدير بتشغيل JavaScript أو جلب صفحات خارجية.

تشمل الاختبارات إنشاء/تعديل/حذف وعزل حسابين ورفض الحقول الخاطئة وCSRF وحصة المجاني وانتهاء التجربة وعدم تكرارها وPDF حقيقي ودورة OAuth أحادية الاستخدام وعقود أخطاء عميل الواجهة. تشغيل المعاينة، حفظ Git، تسجيل نسخة Manus، والنشر الدائم أحداث مختلفة؛ لا يعني دفع فرع GitHub أن النسخة القديمة على استضافة أخرى تغيرت.
