# موجز أداة خدمة عربية

## النتيجة العملية

حوّل مهارة المستخدم إلى عرض خدمة صغير وواضح يمكن تخصيصه وإرساله.

## المستخدم الأساسي

مستقل أو صاحب خدمة يريد البدء بعرض محدد، لا بناء متجر أو منصة متعددة الأطراف.

## مسار الاستخدام

1. اختيار خدمة ذات نتيجة ونطاق وموعد.
2. تعديل السعر والكلفة والهدف.
3. نسخ رسالة العرض بعد تخصيصها.
4. إكمال ثلاث مهام تواصل قصيرة.

## حدود الثقة

- اعتبر الأرقام تقديرات قابلة للتحرير.
- لا تعرض وعود دخل أو ربح مضمون.
- لا تنشئ تقييمات أو شهادات عملاء وهمية.

## لغة التصميم

واجهة RTL دافئة تشبه ورشة تشغيل: عاجي شبكي، فحمي، ليموني وظيفي، محطات 01–03، وملصقات ورقية.
